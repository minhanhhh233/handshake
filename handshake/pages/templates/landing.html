Handshake agent gateway for Valio Aimo, Junction 2026 prototype

I need 1,000 litres of lactose-free milk by Monday.

A hotel's purchasing agent, asking Valio Aimo

Handshake is the gateway that lets a software agent do this safely. The agent can look up products, it receives a signed price it can check, and any order outside the limits a person set waits for that person to approve it.

  • Prices and stock come only as signed, time-limited offers. Anyone can verify the signature.
  • Every order is checked against the customer's mandate on the gateway, never on the agent.
  • Each step is logged in a hash-chained record and summarised in a signed receipt.

Run the example order

The agent finds lactose-free milk, gets a signed offer for 1,000 litres, and checks it against its mandate. The total is over its limit, so you approve it yourself.

Milk-allergy guard

A school kitchen's mandate forbids milk. Lactose-free milk still contains milk, so the gateway refuses every product and says why.

Anonymous search

Without an agent key you can search products and read their attributes, but you never see a price or a stock level.
