    What the gateway does

    Every rule lives on the gateway. The agent decides what to ask for; Handshake decides what is allowed.

    • Lookup

      Structured product search

      Filter by category, claims, allergens and labels. Supplier text is marked untrusted.

    • JWS

      Signed, fixed prices

      Every offer is an Ed25519-signed JWS with expiry. Any agent can verify it with the public key.

    • Mandate

      Limits a person sets

      Spend caps, allergens, categories and delivery days, checked on every order. Never on the agent.

    • Approval

      Human sign-off

      Orders over the mandate wait for a named approver on a phone. The agent never sees the link.

    • Hash chain

      Tamper-evident record

      Each step is hash-chained. The signed receipt carries the chain head, so changes show.

    • MCP

      Works with any agent

      Plain HTTPS with an OpenAPI description, a discovery document, llms.txt and an MCP server.

    Quick start

    Four things to try from a terminal.

    • Read the discovery file

      API base, signing scheme, capabilities and authentication.

      curl {{ base }}/.well-known/handshake.json

    • Search without a key

      Products and attributes; no prices or stock without a key.

      curl "{{ base }}/v1/products?category=10400&claims=FREE_FROM_LACTOSE&limit=5"

    • Verify an offer signature

      Python with PyJWT. Save an offer's JWS, for example from the playground, as offer.jws.

      import json, jwt, urllib.request
jwks = json.load(urllib.request.urlopen("{{ base }}/.well-known/jwks.json"))
jws = open("offer.jws").read().strip()
kid = jwt.get_unverified_header(jws)["kid"]
key = jwt.PyJWK(next(k for k in jwks["keys"] if k["kid"] == kid)).key
print(json.loads(jwt.PyJWS().decode(jws, key, algorithms=["EdDSA"])))

    How it works

    The path of one order, as the agent and the gateway see it.

    1. Search

      The agent filters the catalogue by structured attributes.

    2. Offer

      The gateway prices and signs a time-limited offer.

    3. Check

      A dry run tests the order against the mandate.

    4. Approve

      Over the limit, a named person signs off.

    5. Receipt

      A signed, hash-chained record of every step.
