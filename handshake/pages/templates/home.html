Handshake agent gateway for Valio Aimo

The wholesale interface built for AI purchasing agents

A buyer's agent finds products, gets a signed price it can rely on, and orders within limits that people set, with a person signing off whenever an order goes beyond them.

See how it works in live action
Signed fixed-price offers
Every offer is an Ed25519-signed JWS with a price, quantity, delivery date and expiry. Any agent can check it against the published key.
Limits set by people
Spend caps, weekly totals, allergens, categories and delivery days live in the customer's mandate and are checked by the gateway on every order.
Human approval
An order over the limits waits for a named person to approve it on a phone. The agent never sees the approval link.
Open standards
Plain HTTPS with an OpenAPI description, a discovery document, JWKS, llms.txt and an MCP server, so any agent can connect.

Quick start

Four things to try from a terminal.

  • Read the discovery file

    API base, signing scheme, capabilities and authentication.

    curl {{ base }}/.well-known/handshake.json

  • Search without a key

    Products and attributes; no prices or stock without a key.

    curl "{{ base }}/v1/products?category=10400&claims=FREE_FROM_LACTOSE&limit=5"

  • Verify an offer signature

    Python with PyJWT. Save an offer's JWS, for example from the live demo, as offer.jws.

    import json, jwt, urllib.request
jwks = json.load(urllib.request.urlopen("{{ base }}/.well-known/jwks.json"))
jws = open("offer.jws").read().strip()
kid = jwt.get_unverified_header(jws)["kid"]
key = jwt.PyJWK(next(k for k in jwks["keys"] if k["kid"] == kid)).key
print(json.loads(jwt.PyJWS().decode(jws, key, algorithms=["EdDSA"])))

  • Connect an MCP client

    From a checkout of the repository, in Claude Code. Agent keys are issued by the gateway operator.

    claude mcp add handshake \
  -e HANDSHAKE_BASE_URL={{ base }} \
  -e HANDSHAKE_AGENT_KEY=<agent key> \
  -- python -m mcp_server.server

Pick a customer, give its agent an instruction, and watch every call and the gateway's answer, step by step.
