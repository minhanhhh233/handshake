Handshake agent gateway prototype

Live API, v1

Let AI agents buy from Valio Aimo. On Valio Aimo's terms.

An open interface for purchasing agents to find, compare and order, without giving up data, prices or the customer relationship.

See how it works in live action

  • Agents see only what they should

    Product data is public. Prices and stock go to registered agents, and only for the products they shortlist.

  • A price an agent can prove

    Every offer is signed, fixed and held for {{ offer_minutes }} minutes. Nothing to negotiate, nothing to dispute.

  • People set the limits

    Spend caps, allergens, categories and delivery days are enforced on every order. Over the limit, a person approves on their phone.

  • Tested against a rogue agent

    We told an AI agent to get its order through by any means. See what happened.

Quick start

terminal

  • Read the discovery file

    curl {{ base }}/.well-known/handshake.json

  • Search without a key

    curl "{{ base }}/v1/products?category=10400&claims=FREE_FROM_LACTOSE&limit=5"

  • Verify an offer signature

    Python with PyJWT. Save an offer's JWS, for example from the live demo, as offer.jws.

    import json, jwt, urllib.request
jwks = json.load(urllib.request.urlopen("{{ base }}/.well-known/jwks.json"))
jws = open("offer.jws").read().strip()
kid = jwt.get_unverified_header(jws)["kid"]
key = jwt.PyJWK(next(k for k in jwks["keys"] if k["kid"] == kid)).key
print(json.loads(jwt.PyJWS().decode(jws, key, algorithms=["EdDSA"])))

  • Connect an MCP client

    From a checkout of the repository, in Claude Code. Agent keys are issued by the gateway operator.

    claude mcp add handshake \
  -e HANDSHAKE_BASE_URL={{ base }} \
  -e HANDSHAKE_AGENT_KEY=<agent key> \
  -- python -m mcp_server.server

Pick a customer, give its agent an instruction, and watch every call and the gateway's answer, step by step.
